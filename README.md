# HopeCare - Cancer Awareness Website

A minimalistic, clean single-page website for cancer awareness.

## Live Demo

[View Live Site](https://hope-care-e20w2sxrm-kusheen8s-projects.vercel.app/)

## Features

- **Landing Section**: Beautiful banner with HopeCare title and inspiring message
- **Quotes Section**: Motivational quotes fetched from an external API
- **Contact Form**: Simple contact form with thank you message
- **Responsive Design**: Mobile-friendly layout with clean, modern styling

## Color Palette

- Background: White (#FFFFFF)
- Primary Text: Charcoal Gray (#333333)
- Primary Accent/Buttons: Soft Blue (#4A90E2)
- Secondary Accent: Light Coral (#FF6B6B)

## Files

- `index.html` - Main HTML structure
- `styles.css` - All styling and responsive design
- `script.js` - JavaScript for quotes API and form handling

## Usage

Simply open `index.html` in a web browser. No build process or dependencies required.

## Browser Support

Works on all modern browsers (Chrome, Firefox, Safari, Edge).
